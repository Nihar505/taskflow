# TaskFlow

TaskFlow is a simple command-line task and habit tracker built in Python.

> **Status:** Under Active Development 🚧  
> Stage 1 initial repository setup. Core task and habit tracking features will be introduced in upcoming stages.

## Overview

TaskFlow is designed to help users track daily tasks and habits efficiently right from the terminal.

### Planned Features
- ➕ Add tasks and habits
- 📋 List active tasks
- ✅ Complete tasks
- 🗑️ Delete tasks
- 📅 Assign due dates
- 📊 View basic stats and progress
- 💾 Local data persistence

## Getting Started

### Prerequisites
- Python 3.6+

### Running the Application

To run the application and view the welcome message:

```bash
python3 main.py
```

To display help:

```bash
python3 main.py help
```
